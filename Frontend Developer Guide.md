# **🗳️ Frontend Developer Guide**

Welcome to the project\! This guide is for developers working on the user interface. It explains how to set up your environment and interact with the deployed backend API to build the voting application.  
This guide assumes that the smart contracts and the Firebase backend have already been set up and deployed by the project owner.

## **📋 Prerequisites**

Before you begin, ensure you have the following tools installed:

1. **Git:** For version control.  
2. **Node.js v20:** You must use this version. The easiest way to manage this is with a Node Version Manager (nvm or nvm-windows). Run nvm use 20\.  
3. **Firebase CLI:** The command-line tools for Firebase. If not installed, run npm install \-g firebase-tools.

## **🚀 Step 1: Initial Environment Setup**

First, you need to get the project code and set up your local workspace.

1. **Clone the Repository:**  
   git clone \[https://github.com/AgreeableAK/blockchain-voting-zkp.git\](https://github.com/AgreeableAK/blockchain-voting-zkp.git)  
   cd blockchain-voting-zkp

2. **Switch to the Frontend Branch:** As per the project's workflow, all frontend development happens on the feat/frontend branch.  
   git checkout feat/frontend

3. **Install Root Dependencies:** The project root contains the necessary Semaphore libraries for generating Zero-Knowledge Proofs on the client-side. Install them by running this command from the project's **root directory**:  
   npm install

   This gives you access to packages like @semaphore-protocol/identity and @semaphore-protocol/proof.

## **🔥 Step 2: Connect to the Shared Firebase Project**

To use the backend, you need to be added to the Firebase project and get your local environment connected.

1. **Get Invited:** Ask the project owner to invite your Google account to the Firebase project with the **"Viewer"** role. You will receive an invitation via email; please accept it.  
2. **Log into Firebase:** In your terminal, run:  
   firebase login

3. **Get the Firebase Configuration:** This is the most important step. You need a configuration object to connect your frontend app to the correct Firebase project.  
   * Go to the [Firebase Console](https://console.firebase.google.com/) and select the zk-voting-project.  
   * Click the gear icon ⚙️ and go to **"Project settings"**.  
   * In the "Your apps" section, click the web icon (\</\>).  
   * Give your app a nickname (e.g., "Voting Web App") and click **"Register app"**.  
   * Firebase will display the firebaseConfig object. Copy this entire object. It is safe to use in your client-side code.

## **🔌 Step 3: Using the Backend API**

You have access to one primary API endpoint, a Firebase Cloud Function named castVote. Your frontend's main job is to collect a user's vote, generate a ZK proof, and send this data to the castVote function.

### **API Endpoint: castVote**

This function securely verifies a voter's proof and relays their vote to the blockchain.

#### **Request Payload**

The function expects a JSON object with the following three properties:

| Key | Type | Description |
| :---- | :---- | :---- |
| candidateId | string | The ID of the candidate the user is voting for. |
| nullifierHash | string | The unique nullifier hash generated by the Semaphore identity. |
| proof | object | The full Zero-Knowledge Proof object generated by the Semaphore library. |

#### **Success Response**

If the vote is successfully verified and cast, the function will return a JSON object with the following structure:  
{  
  "message": "Vote cast successfully\!",  
  "transactionHash": "0x123abc..."  
}

#### **Error Response**

If something goes wrong (e.g., an invalid proof, a duplicate vote), the function will throw an error. You should wrap your API call in a try...catch block to handle these cases gracefully.

### **Example: How to Generate a Proof and Call the API**

Here is a complete example. This code would run in your frontend after a user clicks a "Vote" button.  
// 1\. Import all necessary libraries  
import { initializeApp } from "firebase/app";  
import { getFunctions, httpsCallable } from "firebase-functions";  
import { Identity } from "@semaphore-protocol/identity";  
import { Group } from "@semaphore-protocol/group";  
import { generateProof } from "@semaphore-protocol/proof";

// 2\. Add your Firebase Config from the console  
const firebaseConfig \= {  
  apiKey: "AIzaSy...",  
  authDomain: "zk-voting-project.firebaseapp.com",  
  projectId: "zk-voting-project",  
  // ... and so on  
};

// 3\. Initialize Firebase  
const app \= initializeApp(firebaseConfig);  
const functions \= getFunctions(app);  
const castVote \= httpsCallable(functions, 'castVote');

// 4\. Main function to handle the voting process  
async function handleUserVote(candidateId) {  
  try {  
    // \--- Part A: ZK Proof Generation (Client-Side) \---

    // Create a new, anonymous identity for the voter  
    const identity \= new Identity();

    // Create a group and add the new identity's commitment  
    // In a real app, the group would be pre-populated with all eligible voters  
    const group \= new Group();  
    group.addMember(identity.commitment);

    // This is the external signal, which is the candidate ID  
    const signal \= candidateId.toString();  
      
    // In a real app, the poll ID would be a fixed value for the election  
    const externalNullifier \= group.id; 

    console.log("Generating ZK proof...");

    // Generate the proof  
    // NOTE: You will need the ZK circuit files (zkey, wasm) available in your frontend assets.  
    const fullProof \= await generateProof(  
        identity,  
        group,  
        externalNullifier,  
        signal,  
        {  
            zkeyFilePath: "/path/to/your/semaphore.zkey",  
            wasmFilePath: "/path/to/your/semaphore.wasm",  
        }  
    );

    console.log("Proof generated successfully.");

    // \--- Part B: Calling the Backend API \---

    console.log("Sending vote to the backend...");

    const result \= await castVote({  
      candidateId: signal,  
      nullifierHash: fullProof.nullifierHash,  
      proof: fullProof.proof  
    });

    console.log("Backend response:", result.data);  
    alert("Vote cast successfully\! Transaction hash: " \+ result.data.transactionHash);

  } catch (error) {  
    console.error("An error occurred:", error);  
    alert("Failed to cast vote: " \+ error.message);  
  }  
}
